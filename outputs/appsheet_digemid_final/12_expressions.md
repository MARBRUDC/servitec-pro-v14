# Expresiones AppSheet Producción

## LOTES[RELATED_INGRESOS]

```appsheet
REF_ROWS("INGRESOS", "ID_LOTE")
```

## LOTES[RELATED_EGRESOS]

```appsheet
REF_ROWS("EGRESOS", "ID_LOTE")
```

## LOTES[RELATED_DOCUMENTOS]

```appsheet
REF_ROWS("DOCUMENTOS", "ID_LOTE")
```

## LOTES[TRAZABILIDAD_RESUMEN]

```appsheet
CONCATENATE("Producto: ", [ID_PRODUCTO].[NOMBRE], " | Lote: ", [LOTE], " | Stock: ", [STOCK_ACTUAL], " | Vence: ", TEXT([FECHA_VENCIMIENTO]))
```

## LOTES[TOTAL_INGRESOS]

```appsheet
SUM(SELECT(INGRESOS[CANTIDAD], [ID_LOTE] = [_THISROW].[ID_LOTE]))
```

## LOTES[TOTAL_EGRESOS]

```appsheet
SUM(SELECT(EGRESOS[CANTIDAD], [ID_LOTE] = [_THISROW].[ID_LOTE]))
```

## LOTES[STOCK_ACTUAL]

```appsheet
[TOTAL_INGRESOS] - [TOTAL_EGRESOS]
```

## LOTES[DIAS_VENCIMIENTO]

```appsheet
[FECHA_VENCIMIENTO] - TODAY()
```

## LOTES[ALERTA_VENCIMIENTO]

```appsheet
IFS([STOCK_ACTUAL] <= 0, "SIN STOCK", [FECHA_VENCIMIENTO] < TODAY(), "VENCIDO", [DIAS_VENCIMIENTO] <= 30, "VENCE 30 DIAS", [DIAS_VENCIMIENTO] <= 60, "VENCE 60 DIAS", [DIAS_VENCIMIENTO] <= 90, "VENCE 90 DIAS", TRUE, "VIGENTE")
```

## LOTES[PRIMER_INGRESO]

```appsheet
MIN(SELECT(INGRESOS[FECHA], [ID_LOTE] = [_THISROW].[ID_LOTE]))
```

## LOTES[ORDEN_FEFO_FIFO]

```appsheet
COUNT(SELECT(LOTES[ID_LOTE], AND([ID_PRODUCTO] = [_THISROW].[ID_PRODUCTO], [STOCK_ACTUAL] > 0, OR([FECHA_VENCIMIENTO] < [_THISROW].[FECHA_VENCIMIENTO], AND([FECHA_VENCIMIENTO] = [_THISROW].[FECHA_VENCIMIENTO], [PRIMER_INGRESO] < [_THISROW].[PRIMER_INGRESO]))))) + 1
```

## LOTES[ES_LOTE_FEFO]

```appsheet
[ORDEN_FEFO_FIFO] = 1
```

## EGRESOS[STOCK_DISPONIBLE_LOTE]

```appsheet
[ID_LOTE].[STOCK_ACTUAL]
```

## EGRESOS[ES_FEFO_VALIDO]

```appsheet
[ID_LOTE] = ANY(ORDERBY(SELECT(LOTES[ID_LOTE], AND([ID_PRODUCTO] = [_THISROW].[ID_PRODUCTO], [STOCK_ACTUAL] > 0)), [FECHA_VENCIMIENTO], TRUE, [PRIMER_INGRESO], TRUE))
```

# Valid If críticos



## PRODUCTOS[CODIGO]

```appsheet
COUNT(SELECT(PRODUCTOS[ID_PRODUCTO], AND([CODIGO] = [_THISROW].[CODIGO], [ID_PRODUCTO] <> [_THISROW].[ID_PRODUCTO]))) = 0
```

## LOTES[FECHA_VENCIMIENTO]

```appsheet
[FECHA_VENCIMIENTO] >= [FECHA_FABRICACION]
```

## INGRESOS[ID_LOTE]

```appsheet
SELECT(LOTES[ID_LOTE], [ID_PRODUCTO] = [_THISROW].[ID_PRODUCTO])
```

## INGRESOS[CANTIDAD]

```appsheet
[_THIS] > 0
```

## EGRESOS[ID_LOTE]

```appsheet
LIST(ANY(ORDERBY(SELECT(LOTES[ID_LOTE], AND([ID_PRODUCTO] = [_THISROW].[ID_PRODUCTO], [STOCK_ACTUAL] > 0)), [FECHA_VENCIMIENTO], TRUE, [PRIMER_INGRESO], TRUE)))
```

## EGRESOS[CANTIDAD]

```appsheet
AND([_THIS] > 0, [_THIS] <= [ID_LOTE].[STOCK_ACTUAL])
```

